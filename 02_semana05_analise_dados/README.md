# Semana 05 — Sistema de análise de dados

Execute com `python3 main.py`. O programa lê `dados.csv` usando `with`/codificação UTF-8, valida e-mails, CPFs, telefones e datas com regex, trata `FileNotFoundError`, `ValueError`, `KeyError` e `csv.Error`, além de usar a exceção personalizada `FormatoInvalidoError`.

O relatório apresenta o total de registros, os válidos e os inválidos com o motivo de cada rejeição.

Também há uma versão comentada em `main.por`, representando a validação e o tratamento de erros em Portugol.
